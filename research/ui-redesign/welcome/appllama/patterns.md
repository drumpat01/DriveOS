# Welcome findings

## Findings applied

1. Lead with the outcome, not the product category. “Your drives, remembered.” communicates the emotional job before setup begins.
2. Explain the product in one sentence. Route, music, moments, and the private archive are the minimum proof needed to understand JourneyDeck.
3. Preserve the cinematic full-bleed road artwork. The image creates desire; the copy supplies comprehension.
4. Keep one primary action. The welcome is not the place for permissions, sign-in branching, feature carousels, or membership messaging.
5. Set expectations for the next step. The note below the CTA makes recording and music choices feel deliberate and reversible.
6. Put privacy in the value proposition. A compact trust card makes local/private ownership visible before location access is requested.

## JourneyDeck-specific decisions

- Kept the existing theme-specific artwork and static presentation.
- Kept the existing first-run state machine and manual advance behavior.
- Replaced the generic slogan and “Get Started” copy; no permission, persistence, native module, or entitlement behavior changed.
- Used the established theme palette so Grand Touring, Warm Ivory, Rosewater, Cinematic Dark, and Autumn Drive remain supported.
