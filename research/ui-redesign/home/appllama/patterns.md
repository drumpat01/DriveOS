# Appllama synthesis for the JourneyDeck Home pilot

## Pattern adopted

**Action → story → context → summary.**

The strongest references do not behave like a configurable BI dashboard. They establish the job to do, show one emotionally meaningful artifact, add one contextual destination, then summarize the rest. JourneyDeck should use that grammar while retaining its road photography, two premium themes, native five-tab shell, and customizable modules.

## Checkable target

1. The first interactive element below the branded header is the full-width `Record Journey` action.
2. The first content module is `Latest memory` whenever a memory exists; it receives the largest content image on Home.
3. Only one contextual module follows in the default viewport: compact 50 States, Ask JourneyDeck, or latest soundtrack.
4. Listening hours, streak, miles, songs, and journey count are grouped into one quiet summary region rather than five equally framed cards.
5. Customize is absent from the normal reading order. A header menu or grid long-press enters an explicit edit mode presented as a native sheet or modal task.
6. The compact 50 States module shows progress and a cropped/abstracted map preview; the full map opens as its own screen.
7. Grand Touring spends gold only on the primary action, selected state, and progress. Warm Ivory spends coral on the same roles; plum remains decorative/editorial ink.
8. Photography is confined to the atmosphere layer and story modules. Text and controls sit on readable semantic surfaces rather than translucent cards over busy imagery.
9. Home uses one display title, one serif editorial title at a time, and platform text styles elsewhere.
10. The final module can scroll to a fully visible resting position above the native tab bar.

## Module translation

| Reference pattern | JourneyDeck use |
|---|---|
| Mult.dev single creation CTA | Record Journey as the only full-emphasis action |
| Retro photo-story scale | Latest memory as the dominant saved-content module |
| Day One / AllTrails summary card | One coherent road summary for related metrics |
| Visited narrative map | Compact 50 States story that opens the expanded collection |
| Slopes / Gaia contextual sheet | Intentional Home edit/customization mode |
| OS Maps task ordering | Action before exploration, progress, or archive content |

## Motion and behavior

- Keep native tab transitions unchanged.
- Recorder state changes are immediate; the label/value change carries the state, with haptics as punctuation.
- Entering edit mode presents one native transition. Reordering follows the finger and springs only on release.
- Story imagery may cross-fade when its underlying memory changes; metrics do not animate for decoration.
- Reduce Motion removes photo drift and spatial reordering flourish while preserving clear state feedback.

## Side-by-side review criteria

The redesigned Home wins only if, at identical device size and scroll position, it makes these answers faster than the current screen:

- How do I start a journey?
- What is the most recent story from my driving history?
- What progress is worth noticing today?
- Where do I go for the full collection or archive?

It must also show fewer simultaneous borders, fewer accent-colored peers, no orphan half-width metric, and no content obscured by the tab bar.
