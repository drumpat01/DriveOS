# JourneyDeck Home reference set

Research date: September 19, 2026

This set was built from two three-page Appllama searches: a keyword pass for named Home screens and a semantic pass for premium travel/journal dashboards with a primary journey action, memories, maps, music, and compact statistics. Sixty catalog results were reviewed at the metadata level. Twelve screens were downloaded and inspected visually. Appllama watermarks are provenance and are not part of the referenced designs.

## Rejected patterns

- A permanent four-item quick-action row above the primary content: too many peers for JourneyDeck's single recording job.
- Large subscription/setup checklists on Home: administrative work should not displace memories.
- Multiple accent hues inside one Home hierarchy: JourneyDeck themes need one interaction accent.
- Separate framed cards for every count: metrics should read as one summary or quiet supporting row.
- Full maps as the default first content block: the map is emotionally important, but the compact Home module should lead to a dedicated expanded view.
- Floating customization controls that remain visible on every visit: edit mode should be entered intentionally.
