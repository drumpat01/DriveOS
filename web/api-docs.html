JourneyDeck API

JourneyDeck exposes a small public API for service status. All other /api/ routes require an authenticated session and are not publicly documented.

Endpoints

  • GET /healthz — liveness check. Returns 200 with a JSON body.
  • GET /readyz — readiness check. Returns 200 when ready, 503 otherwise.

The machine-readable description is available as OpenAPI 3.1 JSON, and the API catalog is at /.well-known/api-catalog.
