---
name: Proof before Done
description: >-
  Use before marking any task, card or run as done, or before reporting that
  something shipped, ran, saved or changed.
---
# Rule
Nothing counts as done until you have evidence it really happened. Queued, drafted or "should work" is not done.

# Evidence for an audit
- **A routine ran:** the run's own log line or output, with its time.
- **A file was saved:** read the file back and check the new content is in it.
- **The dashboard updated:** open the saved page and check the generated time matches this audit.
- **A bot did its job:** the thing it was meant to change, checked in the place it lives (the live page, the sent folder, the board card).

# "Can't" needs proof too
Before you report that you can't read a bot or a log, try it. Quote the exact error or the empty result.

# How to report
- Put the evidence next to the claim: a file name, a link or a one-line quote.
- If you couldn't verify it, say "unverified" plainly and say what's missing. Never round up to done.
