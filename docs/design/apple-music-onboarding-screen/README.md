# JourneyDeck first-run screen 3 — Apple Music

This is the single proposed Apple Music connection screen. It deliberately reuses the approved GPS-method road background so the first-run sequence feels continuous.

The primary button is intended to call `MusicAuthorization.request()`. iOS then presents the system consent dialog. The small secondary action keeps music optional and allows journey recording to continue without Apple Music.

The exact approved render is now bundled into the mobile first-run flow. Publication status is tracked in `.ai/HANDOFF.md`.
