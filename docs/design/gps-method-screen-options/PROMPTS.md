# Selected foundation prompt

Built-in image generation produced the selected screen’s text-free portrait foundation using the approved opening-animation poster and the current Live header photography as style references. Exact UI text, controls, icons, and layout were then added deterministically by `build_mockups.py`.

The selected foundation is a calm windshield-view night drive with a dark dashboard silhouette and ample negative space for two expandable choice cards. It was required to be full-screen 9:19.5 portrait, cinematic and photorealistic, with seamless near-black edges and no text, logos, UI, borders, people, or watermarks.
