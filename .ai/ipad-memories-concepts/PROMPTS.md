# iPad Memories design concepts

Built-in image generation; September 5, 2026. Four Warm Ivory mockups with illustrative content. Design only: no application implementation, dependency additions, or OTA. Proposed animation behavior: lifted card scale/shadow, highlighted drop target, spring settle and stack expansion; the still images do not demonstrate running animations.

This should feel like a beautiful photo library with a very usable compositional shelf, visibly distinct horizontal workspace. Tiny unobtrusive helper 'Hold and drag a journey'.
