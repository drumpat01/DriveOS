# iPhone Memory Studio concept

Built-in image generation, using the approved iPad Memory Studio as a visual reference. Design only; no app changes or OTA. Illustrative travel records and photography.

Use case: ui-mockup. Generate ONE high fidelity portrait iPhone concept image for JourneyDeck "Memory Studio". Reference image is the approved iPad Memory Studio, use it ONLY as visual brand/style reference. Adapt the layout thoughtfully for a SMALL PHONE, NOT a shrunken side-by-side tablet. One straight-on modern black slim-bezel iPhone, entire device visible on quiet warm neutral studio background, very large in image, readable screen, realistic tall phone proportions. No hands, no extra phones, no external annotations.
Theme exactly JourneyDeck Warm Ivory: background #fffaf0, cards #fffcf6, primary ink #291d26, muted #685461, violet #754487, lilac #eee2ef, thin taupe borders #d8c5ba, orange #ff8956 reserved for Home icon. Polished restrained iOS glass, soft shadows, warm photographic artwork, rounded cards, generous touch targets. System sans-serif interface; tasteful editorial titles within photo cards.
Screen layout:
At top native status time 9:41 and Dynamic Island. Compact panoramic warm coastal road and printed photographs header faded into ivory, title "MEMORIES" large bold letter-spaced matching existing iPhone app.
Below: one small search field "Search Memories" and circular purple plus button. Small heading "Your Memories".
Main upper workspace: TWO substantial tall photo memory cards side by side in two equal columns, beautifully cropped golden coastal road "Pacific Coast" / "5 journeys", and sunlit city skyline "City evenings" / "3 journeys". These are the only memory cards visible so the phone remains airy. One subtle violet outline on Pacific Coast indicates it is a drop target.
Lower workspace: an integrated expandable ivory Journey tray, with drag handle, heading "Journey library", compact upward chevron, helpful readable line "Hold and drag to build your story". Two compact landscape journey rows with actual scenery thumbnails on left, title and concise metadata on right: "Big Sur drive" / "48.7 mi · 12 songs" and "Sunday escape" / "21.4 mi · 6 songs". Tray distinct from app navigation and does not cover the main memory cards. Show an elegant small lifted floating journey card labeled "Big Sur drive" with coast thumbnail and plus badge, halfway between the tray and Pacific Coast card, subtle tilt and shadow, plus a compact "Release to add" cue on the target. Convey a drag interaction in a STILL without pointer, finger, motion streaks or giant arrows; do not obscure titles.
At bottom keep exactly FIVE native iOS style tabs evenly spaced in a single floating translucent ivory capsule: "Music" music note, "Memories" photos icon with lilac selected pill, "Home" solid ORANGE house, "Statistics" chart icon, "Settings" gear. No raised custom Home circle, no sixth tab, no sidebar. Black home indicator below. Whole screen fits without clipped nav or tiny unreadable text.
This is a design concept using illustrative travel data and images, not a screenshot of implemented app. Match reference mood and typography but optimize hierarchy and spacing for phone. Crisp professional UI presentation.
